# 小児処方量監査ツール 仕様書

版: 2026-09-10
対象: `pediatric-dose-audit/`

## 1. 目的と位置づけ

本ツールは、入力された年齢・体重・薬剤・製剤規格・1日処方量・分割回数を、最新の電子添文で確認した小児用法・用量と照合する監査補助ツールである。処方決定を自動化するものではなく、最終判断では適応、患者背景、腎肝機能、禁忌・注意事項および最新電子添文を確認する。

## 2. 入力項目

- 年齢（歳）
- 体重（kg）
- 身長（cm、補助換算に必要な場合）
- 薬剤
- 製剤・規格
- 処方量（1日量）
- 処方量の入力モード（製剤量／力価）
- 分割回数
- 適応・用量区分

薬剤名および処方量の入力欄には、欄の右端に入力消去用の「×」を表示する。処方量を消去した後も、薬剤、製剤・規格、分割回数は保持する。

## 3. 薬剤検索と表示分担

検索候補では商品名・一般名・略称を検索語として受け付ける。候補を選択した後は、情報を次のように分離する。

| 表示欄 | 内容 | 例 |
|---|---|---|
| 薬剤 | 商品名（一般名）。剤形・規格は含めない | ムコダイン（カルボシステイン） |
| 製剤・規格 | 剤形と規格 | ドライシロップ50%、シロップ5% |

検索候補は「薬剤名＋製剤・規格」として表示し、候補を選ぶだけで両方を同時に設定する。

検索文字列はPC版・スマートフォン版で同じ正規化処理を使う。カタカナの商品名・一般名・別名はひらがな入力でも一致させる（例: 「みのまいしん」→ミノサイクリン、「あれじおん」→エピナスチン）。

### 3.1 同一候補の統合

同じ投与量ロジックを共有し、剤形種別・単位・含量が同じ製剤は、先発／後発、DS／ドライシロップ等の表記差だけでは候補を増やさず1件に統合する。統合判定は、正規化した剤形、製剤単位、単位当たり力価、および必要時の製品識別子で行う。

### 3.2 別候補として保持する条件

次のいずれかが異なる場合は、同じ成分でも別候補として保持する。

- 承認された分割回数または投与間隔
- 製剤設計（速放／持続性等）
- 商品として区別する必要がある製剤
- 剤形、規格、単位当たり力価

セファレキシンは次を区別する。

- ケフレックスシロップ用細粒100
- ケフレックスシロップ用細粒200
- L-ケフレックス小児用顆粒（1包1g、分2の持続性製剤）
- ラリキシンドライシロップ小児用10%
- ラリキシンドライシロップ小児用20%

薬剤名は上記製品を通して「セファレキシン」に統一し、製品名・規格は「製剤・規格」欄で区別する。

汎用の「ドライシロップ10%／20%」プレースホルダーは、現行の商品名付き製剤が存在する場合には検索候補へ表示しない。

トミロン／セフテラムは同一の現行20%製剤として統合し、どちらの語でも「トミロン（セフテラム） 細粒小児用20%」の1件を表示する。旧10%製剤は表示しない。

メプチン吸入液ユニット0.3mLは検索候補に表示しない。監査済みレコード自体は削除せず保持する。

簡便性を優先し、外用薬（塗布剤、点眼、点鼻・点耳、吸入、貼付剤、坐剤等）は薬剤名検索および「一覧から選択」の候補に表示しない。「点眼」「点鼻」「点耳」「軟膏」「クリーム」「吸入」「テープ」等を名称に含む候補は名称判定でも除外し、ツロブテロールテープも表示しない。外用薬のみを持つ内部選択肢は非表示かつ選択不可にして、旧一覧処理からも表示されないようにする。監査済みデータは削除せず保持し、将来再表示できる構造とする。

## 4. 製剤量／力価の切替

内部では処方された製剤量を保持し、表示モードのみを切り替える。

`力価 = 製剤量 × 単位当たり力価`

製剤量ボタンと力価ボタンを切り替えても、同じ処方を表す力価量は変わらない。例えば、50%散を製剤1g/dayと入力した状態で力価へ切り替えると500mg/dayを表示し、製剤量へ戻すと1g/dayに戻る。

製剤・規格を変更した場合は、選択した製剤の単位（g、mL、錠、包等）を即時に再描画し、製剤量ボタン、入力欄、結果欄の単位を一致させる。製剤切替時は、その製剤に設定された初期量を読み込み、以前の製剤の単位や値を残さない。

## 5. 判定

電子添文に承認小児用量がある場合は、その用量を主判定とする。判定には1日力価、体重当たり1日力価、分割回数、および定義されている場合は1回量・上限量を使用する。成人量からのAugsberger、Young、Clark、von Harnack、BSA換算は補助表示とし、承認小児用量より優先しない。

電子添文上の対象年齢・体重外、または単一の数値基準を設定できない場合は「判定対象外」とし、推測値で合否を出さない。

## 6. 個別薬剤仕様

### 6.1 ベネトリンシロップ0.04%

- 1mL中サルブタモール0.4mg
- 乳幼児: 製剤0.75mL/kg/day（サルブタモール0.3mg/kg/day）を分3
- 標準1日量: 1歳未満3～6mL、1～3歳未満6～9mL、3～5歳未満9～15mL
- 5歳以上は本ツールの当該乳幼児基準では判定対象外

### 6.2 クラバモックス小児用配合ドライシロップ

- 1.01g中: アモキシシリン600mg（力価）＋クラブラン酸42.9mg（力価）
- 通常: 合計96.4mg/kg/day（AMPC 90＋CVA 6.4mg/kg/day）を12時間ごと、分2、食直前
- 分包製剤は連続的な96.4mg/kg/day計算ではなく、電子添文の体重換算表に該当する製剤量（g/day）を主判定に使用する
- 「添付文書通りの用量」には該当する体重枠と製剤量を表示し、入力された製剤量と一致するかを判定する
- 「今回の用法・用量」では、製剤量に加えてアモキシシリンとクラブラン酸の力価を1日量・1回量に分けて表示する
- 換算式は、AMPC（mg）＝製剤量（g）×600/1.01、CVA（mg）＝製剤量（g）×42.9/1.01とする
- 入力切替の力価は2成分の合計力価として扱い、クラバモックスではボタン名を「合計力価」とする
- 包数監査では0.505g包と1.01g包を使用し、各回を同量かつ未開封包のみで構成できる組合せのうち、1日あたりの総包数が最少のものを表示する。正確に構成できない場合はその旨を表示する
- クラバモックス選択時のみ処方日数欄を表示する。日数入力時は、最少包数の1日分内訳に日数を掛け、0.505g包・1.01g包それぞれの処方全期間の合計包数と総包数を表示する。他剤では日数欄を表示しない

| 体重 | 製剤1日量 |
|---:|---:|
| 6～10kg | 1.01g |
| 11～16kg | 2.02g |
| 17～23kg | 3.03g |
| 24～30kg | 4.04g |
| 31～36kg | 5.05g |
| 37～39kg | 6.06g |

6kg未満および40kg以上は分包製剤の体重換算表外として判定対象外にする。ボトル製剤の調製後懸濁液は0.75mL/kg/dayであるが、分包製剤（g）と混同して判定しない。

### 6.3 抗菌薬の個別表示・上限

- アジスロマイシン細粒は10mg/kgを1日1回・3日間（最大500mg/day）を通常の体重換算基準とする。分包製品を監査するときは適応欄で「分包製品の体重換算表」を選択でき、100mg分包製品の概算表（15～25kg: 200mg/2包、26～35kg: 300mg/3包、36～45kg: 400mg/4包、46kg以上: 500mg/5包）を判定に使用する。この表は添付文書カードにも併記する
- セフィキシムは薬剤名を「セフィキシム（セフスパン）」に統合し、細粒と50mg・100mgカプセルを製剤・規格欄で切り替える。細粒は通常1回1.5～3mg/kg・分2、重症等は1回6mg/kg・分2。カプセルは体重30kg以上で1回50～100mg・分2
- セフジトレンは必要時1回6mg/kgまで、1回200mgかつ1日600mgを上限とする
- セフポドキシムは通常1回3mg/kg・1日2～3回、重症又は効果不十分時は1回4.5mg/kg・1日3回とする
- テビペネムは通常1回4mg/kg・分2、必要時1回6mg/kg・分2とする。現行電子添文に記載のない1回300mg上限は設定しない
- トスフロキサシンは細粒と小児用錠を同じ薬剤名に統合し、製剤・規格欄で切り替える。1回180mgかつ1日360mgを上限とする
- ファロペネムは通常1回5mg/kg・1日3回、必要時1回10mg/kgまでとし、成人での上限用量である1回300mg、1日3回（1日900mg）を超えない
- ホスホマイシンドライシロップ40%とミノサイクリン顆粒2%は、同一規格の重複候補を表示しない。ミノサイクリンは「ミノマイシン」でも検索でき、特に8歳未満での歯牙着色・エナメル質形成不全・一過性骨発育不全の注意を表示する

### 6.4 抗アレルギー薬等の個別表示

- エピナスチンは薬剤名を一般名に統一し、「アレジオン」でも検索できる。用量は「アレルギー性鼻炎」と「蕁麻疹・皮膚疾患に伴うそう痒」に分けて表示する
- エバスチンは錠5mg・10mgのみを表示し、存在しないドライシロップ候補は表示しない
- オキサトミドはドライシロップ小児用2%とシロップ小児用0.2%を同一薬剤の剤形違いとして扱う
- クレマスチンはシロップ0.01%とドライシロップ0.1%を同一薬剤の剤形違いとして統合し、選択剤形の電子添文を表示する。シロップは年齢別4・5・7・10・13mL/day、ドライシロップは0.4・0.5・0.7・1.0・1.3g/dayとし、いずれも分2、1歳未満は個別調整とする
- アタラックス-Pは成人量であることを明記し、皮膚疾患と神経症を分けて表示する。皮膚疾患はパモ酸塩85～128mg/day（塩酸塩50～75mg/day）・分2～3、神経症はパモ酸塩128～255mg/day（塩酸塩75～150mg/day）・分3～4とし、小児の自動適否判定には使用しない
- ファンギゾンは薬剤名を「ファンギゾン」、製剤・規格を「シロップ100mg/mL」とし、同じ語句を重複表示しない
- アスベリンの添付文書カードには、年齢別のチペピジンクエン酸塩1日量と、散10%・ドライシロップ2%・シロップ0.5%・調剤用シロップ2%の製剤量換算表を表示する。スマホでは剤形名・年齢見出しを短縮改行し、5列を初期画面幅内に収めて横スクロールを不要にする
- ケトチフェンは選択剤形に応じて、ドライシロップ0.1%では0.06g/kg/day、シロップ0.02%では0.3mL/kg/dayを、いずれもケトチフェン0.06mg/kg/dayと併記する。年齢別標準1日量表と成人通常量2mg/dayも表示する
- メキタジンは「ゼスラン」「ニポラジン」でも検索でき、薬剤名をメキタジンに統一する。ゼスランシロップ0.03%、ゼスラン小児用細粒0.6%、ニポラジン小児用細粒0.6%は別製品として扱い、気管支喘息と鼻炎・蕁麻疹・皮膚そう痒の用量および年齢・標準体重別表を分けて表示する
- トラニラストは選択剤形に応じて、細粒10%では0.05g/kg/day、ドライシロップ5%では0.1g/kg/dayを、トラニラスト5mg/kg/dayと併記する
- セレスタミン配合シロップは、小児1回5mL・1日1～4回と配合成分量を添付文書カードに表示する

### 6.5 薬剤検索の消去ボタン

- 検索欄の右端には、入力がある間だけ消去用の×ボタンを表示する
- 検索候補ロジックが入力要素を再生成した場合、×ボタンのイベントを現在の入力要素へ再登録する。旧入力要素への登録状態を引き継がず、PC・モバイルとも同じ動作にする

### 6.6 実務用量カード

実務用量は承認用量と混在させず、プレドニゾロンと同じ独立カードで表示する。カードの位置は「添付文書の用法・用量」と「今回の用法・用量」の間とし、従来の結果下部には重複表示しない。

- アスベリン（シロップ、散、ドライシロップ）: 2mg/kg/day・分3を目安とし、病院小児薬用量表の1～2mg/kg/day・分3も補助根拠として併記する
- ペリアクチン（シロップ、散）: 0.25mg/kg/day・分3を目安とし、承認用量とは別の実務用量であることを明示する
- 製剤・規格を切り替えても薬剤単位の実務用量カードを保持する

## 8. 変更・公開手順

1. プレビュー用ブランチで実装する。
2. 用量境界・換算・検索候補・画面操作を検証する。
3. 利用者がプレビューを確認し、公開を承認する。
4. 公開直前の本番コミットをバックアップブランチとして保存する。
5. 差分を再確認して本番へ反映する。

本番差替え時に、同時に無関係な薬剤データやUIを変更しない。
